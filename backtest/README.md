# 海龜策略回測(台股 / 美股 / 加密貨幣)

依 `../turtle-strategy.md` 所述規則實作的事件驅動回測引擎,可套用在台股、美股、
加密貨幣三種標的上。

## 檔案結構

- `turtle_engine.py`:核心邏輯 —— 唐奇安通道突破進場、N 值(ATR)部位規模、
  2N 停損、0.5N 金字塔加碼(上限 4 個單位)、逐日事件模擬。
- `metrics.py`:績效指標(CAGR、最大回落、夏普比率、勝率、獲利因子)。
- `data_loader.py`:資料載入,提供「模擬資料產生器」與「yfinance 真實資料」兩種來源。
- `run_demo.py`:主程式,對台股/美股/加密貨幣三個標的各跑一次回測,輸出權益曲線圖、
  交易明細 CSV 與績效總表。

## ⚠️ 目前的資料限制(請務必先讀)

這個開發環境的網路出口政策只放行 GitHub / npm / PyPI 等白名單網域,
Yahoo Finance、台灣證交所等行情資料來源目前**無法連線**(已實測回應 403)。

因此 `run_demo.py` 預設用**幾何布朗運動模擬**出三段近似台股、美股、加密貨幣
波動特性的價格走勢,只用來驗證回測引擎的邏輯是否正確運作,**結果不代表真實市場報酬**。

## 如何用真實歷史資料回測

在有網路存取權限的環境(自己的電腦、Colab 等):

```bash
pip install yfinance pandas numpy matplotlib
cd backtest
python run_demo.py --real
```

`--real` 模式預設抓取 `2330.TW`(台積電)、`SPY`(美股 ETF)、`BTC-USD`(比特幣),
可在 `run_demo.py` 的 `REAL_TICKERS` 字典自行更換代號,例如:

- 台股:`0050.TW`(元大台灣50)、`2317.TW`(鴻海)
- 美股:`QQQ`、`AAPL`、`TSLA`
- 加密貨幣:`ETH-USD`、`SOL-USD`

## 參數說明

| 參數 | 預設值 | 說明 |
|---|---|---|
| `system` | 2(55/20 突破) | `--system 1` 改用系統一(20/10 突破,含過濾規則以外的簡化版) |
| N 值週期 | 20 日 | ATR(真實波幅移動平均) |
| 每單位風險 | 帳戶權益的 1% | 波動越大部位越小 |
| 停損 | 2N | 觸發即出場,不留倉觀望 |
| 加碼間距 | 0.5N | 最多加碼到 4 個單位 |
| 起始資金 | 1,000,000 | 三個標的各自獨立起算,方便比較 |

## 已知限制(教學/研究用途,非實盤建議)

- 未計入手續費、證交稅(台股賣出 0.3%)、滑價、借券/融券成本;
- 停損/加碼以「當日最高/最低價觸價」簡化判斷,未模擬跳空缺口的極端滑價;
- 台股實際放空有平盤以下不得放空等限制,本引擎的 `allow_short` 是簡化假設;
- 加密貨幣採日曆日(365天/年)、股票採交易日(252天/年)計算年化指標,兩者不宜直接比較夏普值;
- 三個標的目前各自獨立回測、獨立起算資金,尚未做成一個統一資金池的多資產組合回測。
